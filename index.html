PROJECT OVERVIEW

Transforming F1 Data Into Championship Intelligence

This project leverages the rich historical and real-time data from Formula 1 to build a comprehensive analytics platform. Using Tableau's powerful visualization engine, we transform raw race telemetry into actionable insights for fans, analysts, and strategists.

From pole position predictions to championship probability models, this dashboard covers every dimension of modern Formula 1 racing — all in an interactive, explorable format.

Global Race Overview

Circuit-by-circuit analysis across all 24 Grand Prix locations with performance comparisons

Driver Performance Metrics

Lap times, qualifying pace, race pace, overtaking data and consistency analysis

Constructor Championship Battle

Team-by-team points progression, reliability data, and strategic decisions

Pit Stop Strategy Analysis

Tire degradation models, undercut/overcut opportunities, and optimal strategy windows

Championship Success Prediction

Historical patterns and statistical models to forecast championship outcomes
